# 📁 Tema 2: Entorno de Desarrollo

Este tema estudia los entornos de desarrollo integrados (IDE), sus componentes y las herramientas que facilitan la escritura, ejecución, depuración y mantenimiento del código.

## 🎯 Objetivos de Aprendizaje
* Identificar los componentes y las funciones principales de un IDE.
* Utilizar herramientas del editor, la detección de errores, la depuración y la refactorización.
* Relacionar las funciones del IDE con los estados del código y el trabajo en equipo.
