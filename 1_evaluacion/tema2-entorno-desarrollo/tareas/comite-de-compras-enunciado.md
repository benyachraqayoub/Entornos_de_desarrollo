# 🧾 El comité de compras (Enunciado)

* **Asignatura:** Entornos de Desarrollo (1.º DAW)
* **Tema:** Tema 2 - Entornos de desarrollo
* **Actividad:** Auditoría de decisiones sobre IDE
* **Material permitido:** Apuntes y dossier, apartados **3.1 a 4.3 y 6.1 a 6.3**

---

## 📋 La situación

Una empresa ha redactado un acta decidiendo qué entornos de desarrollo va a comprar para cada equipo. **Algunas decisiones son correctas y otras son imposibles o están mal justificadas.**

Tú eres el auditor.

## 📝 Acta del comité · 8 decisiones

1. «El equipo de Fortran trabajará con GNAT Studio, que es libre y funciona en los tres sistemas operativos que usamos.»
2. «Compraremos licencias de Eclipse para el equipo de Java, porque es el IDE libre más conocido.»
3. «El equipo de iOS usará Xcode sobre sus Mac.»
4. «Para el equipo de Basic sobre Linux instalaremos Visual Studio, que soporta Basic.»
5. «Como Visual Studio Community es gratis, Visual Studio deja de ser un entorno propietario.»
6. «Nuestro equipo de C# desarrollará con .NET Framework sobre los portátiles Linux del departamento.»
7. «Da igual el IDE que elija cada uno: como todos usamos SVN, cualquiera nos sirve.»
8. «No hace falta estudiar las funciones de cada IDE: lo importante es acertar con el lenguaje y el sistema operativo.»

---

## ✅ Qué tienes que hacer

1. Marca cada decisión como **correcta** o **errónea**.
2. Para cada decisión errónea, escribe una versión correcta y cita el apartado del dossier que la respalda.
3. Una de las decisiones correctas necesita un matiz: es cierta, pero se queda a medias. Encuéntrala y añade el matiz.
