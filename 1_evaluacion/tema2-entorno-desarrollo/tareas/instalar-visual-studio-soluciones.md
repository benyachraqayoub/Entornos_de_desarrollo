## 🧠 Respuestas a las tres preguntas

### 1. ¿Qué significa que la instalación sea modular?

Significa que puedes elegir qué herramientas instalar. Si eligieras todos los módulos, Visual Studio ocuparía más espacio e instalaría herramientas que quizá no necesitas. Es mejor instalar solo las herramientas que vas a usar.

### 2. ¿Por qué elegir «Desarrollo de escritorio de .NET»?

En esta actividad se crean aplicaciones para Windows con ventanas, botones y formularios. El apartado **6.3** dice que usaremos **C#** con Visual Studio y .NET. El módulo **Desarrollo de escritorio de .NET** incluye herramientas para crear aplicaciones WPF y Windows Forms, así que es el adecuado para este trabajo.

La descripción puede variar un poco según la versión o el idioma. El dossier dice que el módulo compila aplicaciones **WPF, Windows Forms y de consola con C#, Visual Basic y F#**. Anota también la descripción que aparece en tu instalador.

### 3. Si Visual Studio es propietario, ¿por qué no has tenido que pagar?

«Propietario» describe la licencia del programa. No significa que todas las ediciones sean de pago. **Visual Studio Community** es gratis para estudiantes y algunos otros usuarios, si respetan las condiciones de la licencia. Sigue siendo software propietario, no software libre.
