## 🧠 2. Reflexión Final (Elementos Discutibles)

Los tres elementos seleccionados como discutibles son **el navegador web (9)**, **el editor de texto (12)** y **el gestor de bases de datos (13)**. 

* **El navegador web** se puede considerar de sistema si actúa como interfaz operativa o entorno de ejecución en sistemas modernos en la nube.
* **El editor de texto** puede clasificarse como aplicación de oficina si su fin es redactar notas sencillas para un usuario común.
* **El gestor de bases de datos** puede verse como software de aplicación cuando está enfocado al usuario final o analista de datos para tareas específicas de consulta corporativa.
