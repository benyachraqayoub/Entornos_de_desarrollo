
# 🛠️ Entornos de Desarrollo

Este repositorio contiene todas las prácticas, proyectos y ejercicios realizados durante el módulo de **Entornos de Desarrollo** correspondiente a mis estudios en **Desarrollo de Aplicaciones Web (DAW)**:

El objetivo de este módulo es dominar las herramientas esenciales para el desarrollo de software profesional, la gestión de versiones, la optimización de código y las pruebas de software.

## 🚀 Contenidos del Módulo

* **Control de Versiones:** Uso avanzado de Git, flujos de trabajo en GitHub, resolución de conflictos y branching.
* **Entornos de Desarrollo:** Configuración y personalización de IDEs (IntelliJ IDEA, Eclipse, VS Code) y automatización de la construcción (Maven/Gradle).
* **Pruebas y Depuración:** Diseño de pruebas unitarias con JUnit, depuración de código (debugging) y análisis de cobertura de código.
* **Optimización y Refactorización:** Mejora de la calidad del código, patrones de diseño básicos y documentación automática con Javadoc.

## 🛠️ Tecnologías y Herramientas Utilizadas

* **Lenguajes:** Java, Markdown
* **Herramientas de Git:** Git, GitHub
* **IDEs:** IntelliJ IDEA / VS CODE
